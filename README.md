# Vani

Mascota virtual de Vania.

## Instalar en Android

1. Escanea `qr.png` o abre este enlace: [Descargar Vani.apk](https://github.com/AnderFelipeOrtiz2004/proyecto-vaquita/raw/main/vani.apk)
2. Si el celular avisa, permite instalar desde Chrome o el archivo.
3. Abre **vani.apk** y toca instalar.

En iPhone no se puede instalar un APK. Ahí se abre desde el navegador y se añade a la pantalla de inicio.
